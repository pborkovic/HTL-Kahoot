Parameters
$perPage : int = 15

Number of records to display per page. Default is 15. Use smaller values (10-25) for detailed views, larger values (50-100) for compact lists.

$columns : array<string|int, mixed> = ['*']

Array of column names to select. Use ['*'] to select all columns (default), or specify exact columns to optimize query performance and reduce memory usage.

$relations : array<string|int, mixed> = []

Array of relationship names to eager load using Eloquent's with() method. Prevents N+1 query problems. Supports nested relations with dot notation (e.g., 'posts.comments.author').

$where : array<string|int, mixed> = []

Associative array of field => value pairs for filtering. All conditions are combined with AND logic using exact matching. Leave empty for no filtering.

$orderBy : string = 'created_at'

Column name to order results by. Default is 'created_at'. Common values include 'id', 'name', 'created_at', 'updated_at'.

$orderDir : string = 'desc'

Order direction: 'asc' for ascending (A-Z, 0-9, oldest-newest) or 'desc' for descending (Z-A, 9-0, newest-oldest). Default is 'desc'.

Tags
